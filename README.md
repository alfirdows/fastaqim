# Fastaqim · فَاسْتَقِمْ

A one-page ADHD and executive-function coach: one tiny step at a time, a schedule builder, focus timer, strict-but-kind coach, small deeds (dhikr and Quran), notes with spaced review, and rewards.

Open `index.html` in a browser, or use the GitHub Pages link. Progress saves in your browser. Use **Rewards → Back up / restore** to move your history between devices.

A self-help tool, not medical advice.

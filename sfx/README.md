# Bead click sounds

`bead-1.wav` to `bead-5.wav` are single-bead clicks cut from a real field recording:

- "Beads Falling Onto Wood" by juliansmart, Freesound #345511, https://freesound.org/s/345511/
- License: Creative Commons 0 (public domain). No attribution required; credited here anyway.

Cutting: 113 ms around each isolated hit, high-pass 140 Hz, 2 ms fade-in, 60 ms fade-out, peak 0.7.
The tasbih plays a random take each time and tunes pitch, warmth and loudness per bead material (see `SND` in dhikr-plus.js).
